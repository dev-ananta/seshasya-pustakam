Put the app file here, named exactly:

    Seshasya.apk

The "Download for Android" button on the home page links to downloads/Seshasya.apk.

If you would rather link to your GitHub release instead, open index.html,
find id="apk-link", and replace the href with your release asset URL, e.g.

    https://github.com/<you>/<repo>/releases/latest/download/Seshasya.apk

(Using "releases/latest/download/..." always points at the newest release,
as long as the uploaded file keeps the same name.)
